# Limites et politique de livraison

- Vérifications locales Linux Python 3.13; source exacte = B3 récupérée, modifications ciblées et tests complémentaires inclus.
- 142 documents officiels préservés en lecture seule. ECOM OS n'est **pas** un robot de shopping commercial autonome.
- Les moteurs Agents 01/02 et l'Agent 03 simulent décisions/briefs. Ils n'ont pas d'accès Web commercial LIVE authentifié, ni de connexion payante MarketPulse/Higgsfield.
- Dans LLM_Provider runtime, ses outils Web autorisés peuvent produire de vraies pistes et des observations; elles restent en quarantaine `UNVERIFIED` tant que leur provenance n'est pas indépendamment établie. Les démonstrations sont fictives.
- Les 14 questions de sélection produits demandent chacune des références; la présence d'un identifiant de référence ne démontre pas à elle seule la validité commerciale de l'affirmation.
- Aucune revendication de validation macOS native ou d'exécution de LLM_Provider runtime par le constructeur.
- Les tests automatiques contrôlent les scénarios codés, ils ne garantissent pas l'absence de failles futures.
