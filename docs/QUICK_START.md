# Démarrer en 3 minutes

1. Lire `INSTALL_MAC.md` ; le ZIP final est indépendant de l'ancien ECOM OS.
2. Ouvrir le dossier et lancer `DEMARRER_MAC.command` (ou `sh DEMARRER_MAC.command` dans Terminal). Choisir 1 pour le healthcheck, 2 pour la démo fictive ou 3 pour ouvrir LLM_Provider runtime si la commande existe.
3. Dans LLM_Provider runtime, copier-coller le contenu de `PROMPT_DEMARRAGE_AGENT.txt`.

**Important** : le moteur ECOM OS reste REPLAY et les captures Web dans `RESEARCH_INBOX` sont `UNVERIFIED` jusqu'à contrôle externe indépendant. Il n'existe aucune autorisation automatique de dépenses.
